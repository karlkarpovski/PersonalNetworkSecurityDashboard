# Dashboard UI

Use dark Neumorphism (Soft UI) for new dashboard work. Reuse the surface and shadow tokens in `frontend/src/styles.css`. Use raised surfaces for cards and actions, and inset surfaces for active navigation, pressed controls, and status wells. Keep text and focus indicators high-contrast and pair status colors with visible labels. Preserve cyan for outbound traffic, orange for inbound, green for healthy, yellow for warnings, and red for high-priority alerts.

Use the [Phase 2 layout guidance](docs/roadmap.md#dashboard-layout) when adding future views.
